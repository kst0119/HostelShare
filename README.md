# HostelShare – Initial Prototype

## Project
Smart Peer-to-Peer Borrowing and Resource Management System for hostel students.

## Prototype scope
This initial front-end prototype demonstrates:
- Student dashboard
- Browse/search available items
- Post a borrowing requirement
- Basic smart-match interaction
- Transaction and return tracking
- QR handover verification status (prototype representation)
- Due-date reminder message

## Run locally
1. Open `index.html` in a modern browser.
2. No server or database is required for this prototype.
3. For the next iteration, connect the UI to Node.js/Express APIs and MySQL.
